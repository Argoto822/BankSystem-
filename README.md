# BankSystem

Банковская система на C# (WPF) — учебный проект для демонстрации основных принципов объектно-ориентированного программирования и работы с Git.

## Описание

Проект моделирует базовые операции банковской системы:
- Создание и управление банковскими счетами
- Пополнение и снятие средств
- Переводы между счетами
- Просмотр истории транзакций
  -Оформление кредита
## Технологии

- **Язык:** C#
- **Среда разработки:** Visual Studio 2026
- **Система контроля версий:** Git
